# Azure Home Lab — Entry-Level IT Portfolio

Small Azure lab simulating a company's IT environment — identity 
management, cloud administration, networking, and troubleshooting — 
built to demonstrate practical Help Desk / IT Support readiness.

## Overview
See [Capstone-Overview.md](Capstone-Overview.md) for the full project 
summary, architecture, and skills demonstrated.

## Tickets
All work is documented as realistic support tickets in 
[Tickets.md](Tickets.md), covering:
- User & access management (Microsoft Entra ID, RBAC, least privilege)
- Cloud storage provisioning
- Network security (NSG rules, priority logic)
- Troubleshooting (permission mismatches, propagation delays)
- Monitoring & alerting

## Tech Stack
Microsoft Azure · Microsoft Entra ID · Azure RBAC · Azure Storage · 
Virtual Networks & NSGs · Azure Monitor
